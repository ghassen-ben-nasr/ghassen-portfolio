# Tabkha Express

Site vitrine (HTML / CSS / JavaScript vanilla) pour un service tunisien de **boxes repas** :
chaque box contient les ingrédients prêts à l'emploi et une recette guidée — *« Cuisiner sans savoir cuisiner »*.

## Fonctionnalités

- **27 boxes** classées en entrées, plats et desserts (Soupe, Brik, Tajine, Ojja, Couscous, Lablebi, Mloukhia, Zgougou, Bsissa, Masfouf…).
- **Filtres** par type (entrée / plat / dessert) et par temps de préparation (5 → 30+ min).
- **Recherche** instantanée par nom, avec alias franco-arabes (`ojja`, `3jja`, `slata tounsia`, `9leya`…).
- **Catégories d'usage** : Étudiant, Camping, Ramadan, Aïd Fitr, Aïd Odhha, Mouled, Achoura, Nouveau-né, Mariage, Box personnalisée.
- **Panier** avec calcul du total, popups **Log in / Sign up** et popup **Contact**.
- **Multilingue** : Français / English / Darja.

## Lancer

Aucune dépendance, aucun build : ouvrir `index.html` dans un navigateur.

> Les images et les icônes (`assets/`) ne sont pas versionnées dans ce dépôt ; seuls le HTML, le CSS et le JS le sont.

## Stack

`HTML5` · `CSS3` · `JavaScript` (vanilla)
